# Customer Shopping Behavior Analysis

**A Data Analytics Portfolio Project using Python, SQL and Power BI**

## Project Overview

This project focuses on analyzing customer shopping behavior to identify purchasing patterns, customer preferences, and business trends.

The objective is to transform raw customer shopping data into meaningful insights that can help businesses understand their customers and make better data-driven decisions.

The project covers different stages of the data analytics process, including data exploration, data cleaning, SQL-based analysis, and dashboard visualization.

## Project Objectives

- Understand customer purchasing patterns.
- Analyze customer preferences and shopping trends.
- Identify important business insights from customer data.
- Use SQL queries to answer business-related questions.
- Present key findings through an interactive Power BI dashboard.

## Tools and Technologies

- **Python:** Data cleaning, data preprocessing and exploratory data analysis.
- **Pandas & NumPy:** Data manipulation and analysis.
- **Matplotlib & Seaborn:** Data visualization.
- **SQL:** Querying data and extracting business insights.
- **Power BI:** Dashboard creation and visualization.
- **Google Colab:** Running Python notebooks.

## Project Workflow

### 1. Data Exploration and Preparation – Python

- Imported the customer shopping dataset.
- Explored the dataset to understand its structure.
- Examined missing values and data inconsistencies.
- Prepared the data for further analysis.

### 2. Data Analysis – SQL

- Used SQL queries to analyze customer shopping information.
- Explored purchasing patterns and customer segments.
- Answered business-related questions using SQL.

### 3. Dashboard and Visualization – Power BI

- Used Power BI to visualize customer shopping data.
- Presented important business metrics and trends.
- Created an interactive dashboard to make insights easier to understand.
